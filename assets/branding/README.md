# EAL Track identity

`eal-track.png` is the app's master logo, generated with the built-in ImageGen
tool and resized to 1024 × 1024 for app packaging. Android launcher variants are
in `android/app/src/main/res/mipmap-*`; the adaptive icon uses an inset to keep
the mark visible under circular and rounded-square launcher masks.
